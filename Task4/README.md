# Задание 4. Оценка узких мест при миграции

## Описание

В рамках задания был проведен анализ потенциальных узких мест при миграции компании «Медикаменте» с текущей монолитной и файловой архитектуры на современную микросервисную платформу.

Для анализа использовалась диаграмма Исикавы («рыбья кость»), позволяющая выявить корневые причины возможных проблем при миграции.

---

## Выявленные категории рисков

В диаграмме были рассмотрены следующие категории:

- Инфраструктура
- Программное обеспечение
- Данные и интеграции
- Безопасность
- Процессы
- Персонал

---

## Основные выявленные проблемы

- единая точка отказа в виде физического сервера;
- файловый режим работы 1С;
- отсутствие централизованного мониторинга и observability;
- отсутствие RBAC/ABAC и аудита доступа;
- хранение данных в Excel/PDF/JPG;
- ручные процессы обработки данных;
- риски конфликтов данных при миграции;
- недостаточная масштабируемость текущей архитектуры.

---

## Предложенные меры

Для снижения рисков миграции предложены следующие подходы:

- использование Kubernetes и отказоустойчивой инфраструктуры;
- внедрение централизованного мониторинга и логирования;
- применение RBAC/ABAC и IAM;
- внедрение CI/CD и feature toggles;
- использование Parallel Run для постепенной миграции;
- применение Branch by Abstraction;
- внедрение Event Sourcing и асинхронной синхронизации данных.
