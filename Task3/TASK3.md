# Task 3. Data Encryption at Rest and In Transit

| Данные | В чем необходимость защиты | Инструменты защиты |
|---|---|---|
| Персональные данные пациентов (ФИО, телефон, email, дата рождения) | Содержат PII. Утечка приведет к нарушению конфиденциальности и требованиям законодательства РФ | TLS, шифрование БД, RBAC/ABAC, Keycloak, Audit Log |
| Медицинские карты и диагнозы | Содержат PHI и медицинскую тайну | Шифрование БД, ограничение доступа по ролям, аудит доступа, SIEM |
| Результаты анализов | Передаются во внешнюю лабораторию, возможна утечка при интеграции | TLS/mTLS, API Gateway, токенизация, аудит запросов |
| Договоры, PDF/JPG-сканы документов | Могут содержать PII и PHI | Secure Document Storage, шифрование файлов, IAM, DLP |
| Платежные данные и чеки | Финансовая информация должна быть защищена от изменения и утечки | TLS, шифрование БД, RBAC, контроль целостности |
| Данные бухгалтерии и зарплат | Содержат финансовые и кадровые данные | Шифрование хранилища, VPN/TLS, аудит операций |
| Логи и технические события | В логах могут оказаться чувствительные данные | Маскирование логов, централизованный логинг, SIEM |
| Аудит действий пользователей | Необходим для расследования инцидентов и контроля доступа | Audit Log Service, неизменяемое хранилище, SIEM |
| Сырые данные Data Lake (Raw Zone) | Содержат полные данные пациентов до обезличивания | Шифрование Data Lake, изоляция зоны, Data Catalog |
| Обезличенные аналитические данные | Риск повторной идентификации пациента | Маскирование, анонимизация, RBAC для аналитиков |
| Резервные копии БД и файлов | Бэкапы содержат полные копии данных системы | Шифрование резервных копий, KMS/Vault, контроль доступа |
| API-ключи, токены и секреты | Компрометация даст доступ ко всей системе | Vault/KMS, ротация ключей, запрет хранения в коде |

## Автоматизированный контроль

| Средство контроля | Назначение |
|---|---|
| SIEM / Monitoring / Alerting | Выявление нетипичных действий и массовых выгрузок |
| Audit Log Service | Аудит доступа и изменений данных |
| Data Catalog / Tagging Service | Тегирование PII, PHI, FIN, DOC |
| DLP | Поиск и предотвращение утечек данных |
| Data Lineage | Контроль движения данных между системами |

## Реестр средств защиты

| Средство | Назначение |
|---|---|
| Keycloak | IAM, RBAC/ABAC |
| API Gateway | Контроль и защита API |
| Vault / KMS | Хранение ключей и секретов |
| Secure Document Storage | Защищенное файловое хранилище |
| SIEM | Мониторинг и алертинг |
| DLP | Контроль утечек |
| Data Masking Service | Маскирование и обезличивание |
| Audit Log Service | Централизованный аудит |
| TLS/mTLS | Шифрование передачи данных |
| Backup Encryption | Шифрование резервных копий |
